# 🌍 Atlas

### Descubra o mundo. Explore destinos. Planeje sua próxima aventura.

O **Atlas** é uma plataforma de descoberta de destinos turísticos, desenvolvida para ajudar usuários a explorar lugares, conhecer novos destinos e organizar suas experiências de viagem por meio de uma interface moderna, intuitiva e responsiva.

🔗 **Acesse o projeto:** [Explorar Atlas](https://fabioalx29.github.io/Projeto-Atlas/)

---

## ✨ Funcionalidades

- 🌎 **Descoberta de destinos:** Explore diferentes destinos e conheça novos lugares.
- 🔎 **Busca e exploração:** Encontre destinos de maneira simples e intuitiva.
- 🗺️ **Mapas interativos:** Visualize localizações por meio de mapas interativos.
- ❤️ **Favoritos:** Salve seus destinos preferidos para acessá-los facilmente.
- ✈️ **Planejamento de viagens:** Organize e gerencie seus planos de viagem.
- 🌤️ **Informações meteorológicas:** Consulte informações sobre o clima dos destinos.
- 🌐 **Suporte a múltiplos idiomas:** Interface com suporte a diferentes idiomas.
- 📱 **Design responsivo:** Experiência adaptada para computadores, tablets e celulares.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Finalidade |
|---|---|
| React 19 | Construção da interface |
| TypeScript | Tipagem estática |
| Vite | Ambiente de desenvolvimento e build |
| Tailwind CSS | Estilização |
| React Router | Navegação entre páginas |
| i18next | Internacionalização |
| React Leaflet | Mapas interativos |
| Open-Meteo | Dados meteorológicos |

## 🚀 Como executar o projeto

### Pré-requisitos

- Node.js
- npm

### Instalação

1. Clone o repositório:

```bash
git clone https://github.com/Fabioalx29/Projeto-Atlas.git
```

2. Acesse a pasta do projeto:

```bash
cd Projeto-Atlas
```

3. Instale as dependências:

```bash
npm install
```

4. Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

5. Acesse o endereço local exibido no terminal.

## 📦 Build de produção

Para gerar a versão de produção:

```bash
npm run build
```

Para visualizar a versão de produção localmente:

```bash
npm run preview
```

## 🌐 Publicação

O Atlas está publicado no **GitHub Pages**, utilizando **GitHub Actions** para automatizar o processo de build e publicação.

A cada atualização enviada para a branch `main`, o fluxo de publicação executa automaticamente o processo de construção e implantação da aplicação.

## 🎯 Objetivo do projeto

O Atlas foi desenvolvido como um projeto de portfólio com foco no desenvolvimento front-end, colocando em prática conhecimentos como:

- Desenvolvimento de interfaces com React.
- Organização de componentes reutilizáveis.
- Tipagem e estruturação com TypeScript.
- Criação de layouts responsivos.
- Integração com APIs externas.
- Implementação de mapas interativos.
- Gerenciamento de rotas e navegação.
- Internacionalização de aplicações.
- Build e publicação automatizada.
